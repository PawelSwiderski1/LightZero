# Curated research results

This directory contains compact reports selected from local or cluster runs.
Large checkpoints, replay buffers, videos, and raw diagnostics remain outside
Git under `.local_runs`, `.hpc_runs`, or `hpc_results`.

## Recent-history transformer encoder comparison

The directory `recent_transformer_encoder_comparison_1024` contains the nine
raw JSON reports for three observation encoders and three training seeds. See
its README for the dataset definition, aggregate results, and reproduction
command.
