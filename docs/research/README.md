# Research documentation

This directory records the development of the ensemble-MuZero exploration
work carried out in this repository.

- [Research narrative](research_narrative.md) is the meeting-oriented account:
  what was tried, what happened, why each approach was retained or rejected,
  and how one experiment motivated the next.
- [Experimental history](experimental_history.md) is the detailed evidence
  record, including quantitative results, implementation changes, limitations,
  and current conclusions.
- [Experiment registry](experiment_registry.md) is the compact provenance index
  for the run families and diagnostic artifacts referenced by the history.
- [Current handoff](current_handoff.md) records the active Branching Rooms
  revisit-prediction implementation, the October transformer experiments, and
  the exact continuation steps for another machine.
- [Curated results](results/) contains small reports that are useful for
  reproducing decisions without tracking full run directories.

The narrative and detailed history cover the main research line through
2026-09-04. The current handoff extends the operational record through the
recent-history transformer encoder comparison completed on 2026-10-28.
